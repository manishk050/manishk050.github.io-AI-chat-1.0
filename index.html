🌐 Firecrawl

Firecrawl is only enabled after you enter your API key. This app keeps the key in memory for this session and does not save it to localStorage. The supplied Firecrawl skill is used for routing: search first, scrape known URLs, map before crawl when discovery is needed, crawl for bulk extraction, interact when navigation is required, and use the research index for papers/GitHub.
